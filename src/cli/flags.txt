  -add-label value
    	Add a GitHub label to every PR in the stack (repeatable; overrides config add_label)
  -add-tip-label value
    	Add a GitHub label to the tip (top) PR only (repeatable; overrides config add_tip_label)
  -branch-from-title
    	Accepted compatibility switch; branch selection is unchanged
  -default-tags string
    	Set default tags for the current repository (comma separated)
  -draft
    	Create draft PRs; use -draft=false to create ready-for-review PRs (default true)
  -draft-pattern string
    	Wildcard pattern(s) for draft detection (default: wip:*,draft:*,*[wip]*,*[draft]*; comma-separated)
  -dry-run
    	Show what would be done without making changes
  -gh-hosts string
    	Path to config.json (default "~/.config/gh/hosts.yml")
  -github-stack
    	Create/update a GitHub Stack after pushing PRs (disabled by default)
  -include-draft
    	Include draft commits (override config)
  -hyperlinks mode
    	PR links in rich results: auto|always|never (config git-pr.hyperlinks; default auto)
    	Use never for visible URLs; --output=url retains complete addresses; always bypasses detection only in rich results
  -use-icon-font
    	Use Nerd Fonts-compatible icon glyphs (default true; config git-pr.useIconFont); false selects Unicode symbols
  -include-other-authors
    	Create PRs for commits from other authors (default to false: skip)
  -no-stack
    	Do not create/update a GitHub Stack (compatibility override)
  -output string
    	Format of the PR list printed after push: url|url-title|markdown, or a template like '{url} {title}'
  -stack-up
    	Display the stack with its base at the bottom and tip at the top (default true; false inverts it)
  -reverse
    	Deprecated alias for -stack-up; retains the same Boolean value
  -skip-draft
    	Skip commits with [draft] in title
  -stop-after string
    	Stop after phase: validate|get-commits|prepare|push|pr-create (rewrite is an alias)
  -t string
    	Set tags for current stack, ignore default (comma separated)
  -timeout int
    	API call timeout in seconds (default 20)
  -v, --verbose	Decision explanations and operation timings
  -version
    	Show version information
  -y	Assume "yes" to prompts (shorthand for --yes)
  -yes
    	Assume "yes" to prompts (for non-interactive use)
  -compact-stack
    	Use adjacent-PR navigation instead of the full stack footer (default false)
  -read-timeout int
    	Structured command deadline in seconds (default 120; config git-pr.readTimeout)
  -command-timeout int
    	Backend and publication command deadline in seconds (default 600; config git-pr.commandTimeout)
  -vv, --debug	Verbose output plus detailed command and HTTP diagnostics (also -v -v)
